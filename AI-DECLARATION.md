## Notes

Brewlist is built through conversational AI pair-programming (Claude Code):
the maintainer directs features, tests real decks/collections against the
running app, and reviews and approves every change, but the code itself —
across nearly the entire history of this project — is written by AI acting
autonomously on each request through to a working, verified result.

This follows the [AI-DECLARATION](https://ai-declaration.md) standard and
the [REAL Rating](https://www.realgoodai.org/real-rating) (Level 5 — Full
AI) self-disclosure system.
